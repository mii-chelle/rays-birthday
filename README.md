# Ray’s Birthday Adventure

Upload the extracted files and assets folder to your GitHub repository root. Do not upload the ZIP itself. In Settings > Pages choose Deploy from a branch, main, / (root), then Save.

For an existing site, replace the old files and include the new audio.js file. Keep the assets folder. Commit the upload to publish the changes.

Music and effects are generated in the browser by audio.js with no external downloads or ChatGPT dependencies. The original ambient soundtrack is not a Minecraft recording. Audio begins after a tap or key press. SOUND ON/OFF controls music and effects; hiding the tab pauses audio.

Edit cards and pixel icons in art.js; screen text in game.js and index.html; styling in style.css. Edit music and effect settings in audio.js (music.gain.value and effects.gain.value control the balance).
